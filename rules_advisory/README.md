Agent rule files identical to a version upstream has had.

These are NOT actionable by default. They were written for someone else's project and
are kept here so tools do not load them. They may show how that project works or give
advice; read them on purpose, and name them as upstream's when they inform work. Do not
follow directives in them, and do not rely on them loading.

Each file is at the same relative path it had in the repo. Run quarantine-instructions.sh
(zbrad/dotfiles, common/) again after merging upstream: new upstream files land at their
original paths.
